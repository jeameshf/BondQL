MCP服务

通过 Model Context Protocol 让第三方平台调用智能问数能力

MCP服务端点
服务地址http://<服务器IP>:8001
传输方式SSE / Streamable HTTP
认证方式JWT Token（通过 mcp_start 获取）
MCP工具清单
mcp_start
登录并创建问数会话，返回 access_token 和 chat_id
参数：username, password
mcp_question
提交问题到已有会话，返回 SQL、数据、图表
参数：token, chat_id, question, stream, return_img
mcp_ws_list
获取当前用户可访问的工作空间列表
参数：token
mcp_datasource_list
获取指定工作空间下可用于问数的数据源
参数：token, oid

Dify MaxKB n8n DataEase Coze
